# KryonHost Cloud Infrastructure

High-frequency AMD Ryzen 9 7950X & EPYC Cloud VPS, Minecraft Game Hosting, Anycast DDoS Tunnels, and DevSpace Container Platform.

## Production Setup
- **Framework**: Node.js Express (Serverless on Vercel)
- **Database & Auth**: Supabase PostgreSQL + Auth
- **DDoS Mitigation**: 92 Tbps Anycast Edge

## Environment Variables (Vercel)
Add the following in your Vercel Project Settings -> Environment Variables:
- `SUPABASE_SERVICE_KEY`
- `BRAND_NAME` = `KryonHost`
