Setup: Five Minutes. One DNS Record.

01
Create a network
Sign up, name your network, and provide your backend's IP address. You receive an assigned Anycast endpoint hostname immediately.
02
Point your DNS
Add one CNAME (or SRV) record at your registrar. No server migration, no messy plugins, no host change — your server stays exactly where it is.
03
You're protected
Traffic now enters through the global edge. Attacks are absorbed and filtered before they reach you; clean players pass with real IPs intact.
DNS ZONE CONFIGURATION — YOURSERVER.NET DNS ZONE / REGISTRAR
# BEFORE — origin IP exposed to attackers
play    IN  A      203.0.113.7

# AFTER — origin hidden behind EnderShield edge
play    IN  CNAME  a1b2c3.edge.ender.link.

# Or keep a custom port using SRV record:
_minecraft._tcp.play IN SRV 0 5 25565 a1b2c3.edge.ender.link.
