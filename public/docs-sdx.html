KryonHost SDX API Storage Data eXchange v1.0

High-performance distributed object storage engine for game saves, backups, AI models, and production media. Upload files up to 1TB with 5MB chunking, auto-resume, zero egress fees, and sub-10ms latency across India.

Overview & Architecture

Chunked Uploads
Files are split into 5MB chunks for maximum upload throughput and failure-resilience.
Up to 1TB Files
Handles massive database dumps, world archives, and datasets seamlessly.
Zero Egress Fees
Download and stream media without unexpected per-gigabyte bandwidth surcharges.

🔒 Security & Authentication Architecture: All customer API interactions route securely through kriyonhost.vercel.app/api/storage/* proxy backend with verified user sessions, preventing any exposure of master node credentials.

Initialize Upload

POST

Initializes a chunked file upload, calculates chunk requirements, and allocates a unique session ID.

Endpoint 
POST /api/storage/upload-init?node=node-1&path=/backups
ParameterTypeDescription
fileNameStringName of the file to upload (e.g. world.tar.gz)
fileSizeIntegerTotal size in bytes (max 1TB)
totalChunksIntegerNumber of 5MB chunks (Math.ceil(fileSize / (5*1024*1024)))
mimeTypeStringMIME type of the file
JavaScript
async function initUpload(file, path = '/', node = 'node-1') {
  const totalChunks = Math.ceil(file.size / (5 * 1024 * 1024));
  const res = await fetch(`/api/storage/upload-init?node=${node}&path=${path}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      fileName: file.name,
      fileSize: file.size,
      totalChunks,
      mimeType: file.type || 'application/octet-stream'
    })
  });
  return await res.json();
}

Complete Upload

POST

Merges all uploaded chunks into the final destination file on the NVMe node.

JavaScript
async function completeUpload(uploadId) {
  const res = await fetch('/api/storage/upload-complete', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ uploadId })
  });
  return await res.json();
}
