Under The Hood

How EnderHost Controls Your VPS

Direct API proxying to bare-metal KVM hypervisors with zero token leaks and sub-second response times.

STEP 01

Customer Action

Your customer clicks "Start", "Reboot", or "Create Snapshot" on the EnderHost website control panel from their dashboard.

STEP 02

Secure Server Proxy

The EnderHost Node.js backend validates customer identity and session. The secret Shulker reseller token is injected server-side and never exposed to the client browser.

STEP 03

Hypervisor Execution

The request hits api/reseller-v1/ and forwards directly to the host node running QEMU/KVM in Mumbai or Delhi, managing the VM process via Unix sockets.

STEP 04

Instant Real-Time Stream

Host telemetry (% CPU, RAM RSS, QCOW2 disk usage) and kernel serial console output stream right back to the client's browser in real-time.
